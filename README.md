# АЖПК — Онлайн-поступление

Мобильное приложение (Flutter) для подачи заявления в колледж онлайн.

## Экраны
1. Главная страница
2. Регистрация / Вход
3. Выбор специальности (поиск + фильтры)
4. Загрузка документов
5. Проверка и подача заявления
6. Статус заявления
7. Личный кабинет

## Запуск
1. Установите [Flutter SDK](https://docs.flutter.dev/get-started/install) и Git.
2. Склонируйте проект и перейдите в папку:
   ```
   git clone <ссылка-на-ваш-репозиторий>
   cd ajpk_app
   ```
3. Создайте файлы платформ (android, web, windows) — один раз:
   ```
   flutter create .
   ```
4. Установите зависимости и запустите:
   ```
   flutter pub get
   flutter run -d chrome
   ```

## Примечания
- Данные хранятся в памяти (после перезапуска сбрасываются).
- Загрузка документов пока имитируется. Для реальных файлов подключите пакет `file_picker`.
- Контакты на главной странице — примерные, замените на реальные.
